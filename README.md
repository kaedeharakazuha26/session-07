# Session 7 - Student Record Application
## Topics Practiced
- Arrays and objects
- Arrays of objects
- Nested score arrays
- map(), filter(), find(), reduce()
- Arrow functions
- Template literals
- Destructuring
- Spread syntax
- JavaScript modules
## Application Features
- Displays student records
- Calculates each learner average
- Shows passing status
- Searches students by name
- Filters by section and status
- Finds one student by ID
- Calculates the class average
## What I Learned
I learned how arrays and objects can represent real student data and how JavaScript array methods can
transform, search, filter, and summarize that data.
